## 📄 Description

**Chroma Pulse** is a static website project built using HTML, CSS, and JavaScript to simulate a modern streaming platform interface. It showcases the core layout and UI components a real-world streaming service would offer, such as featured streams, categories, and user sections.

## 🚀 How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/KyneLaggui/vanilla-streaming-platform.git
   ```

2. Navigate into the project folder:

   ```bash
   cd vanilla-streaming-platform
   ```

3. Open the project:

   - Option 1: Open `index.html` directly in your web browser.
   - Option 2: Use **Live Server** extension in VS Code for better performance:
     - Right-click `index.html` → "Open with Live Server"

> 💡 No build tools or dependencies needed — it's a static project.
